## הרקע בשורה אחת

הקואורדינטות שלנו הגיעו ממרשמי כשרות ומ-OSM, ורבות מהן היו placeholder של מרכז העיר.
**וייז מדויק יותר מכולם בישראל** — גוגל מפות, אפל מפות ו-OSM פחות — ולכן וייז הוא מקור האמת שלנו לקואורדינטות.
כל רשומה שסונכרנה מסומנת `locationSource: "waze"` ו-`locationPrecision: "exact"`.

המפה שלנו (Leaflet על אריחי OSM) מציירת את הסימנים **ישירות מהשדה `location`** — ראה `src/components/map/leafletHtml.ts:30`.
כלומר תיקון קואורדינטה מתקן בבת אחת את המפה, את הניווט, את מיון "קרובים אליך" ואת חישוב המרחק.

## איך מריצים

```bash
# בדיקה יבשה קודם — תמיד
node scripts/waze-sync-coords.mjs --filter food --resume --dry

# ואז באמת
node scripts/waze-sync-coords.mjs --filter food --resume
```

`--filter` מקבל: `all` · `food` · `tzohar` · `stacked` (רק ערימות) · או שם סוג בודד.
`--resume` מדלג על מה שכבר סונכרן. הסקריפט שומר checkpoint כל 50 רשומות.
